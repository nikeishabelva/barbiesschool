# Barbie School — School Announcement Center

Aplikasi pengumuman sekolah berbasis HTML/CSS/JavaScript yang siap di-host di GitHub Pages.

## Fitur
- Dashboard pengumuman
- Pencarian dan filter kategori
- Detail pengumuman dalam modal
- Agenda sekolah
- Form tambah pengumuman
- Penyimpanan data dengan LocalStorage
- Responsive untuk laptop dan HP
- Tema soft pink + putih

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`.
3. Buka Settings → Pages.
4. Pilih Deploy from branch → `main` → `/root`.
5. Simpan dan buka URL GitHub Pages yang diberikan.
